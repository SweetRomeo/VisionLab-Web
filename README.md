# VisionLab Web

Web interface and REST API for the VisionLab computer vision benchmarking platform.

## Architecture

VisionLab benchmark and experiment results

        ↓

Spring Boot REST API

        ↓

React Web Dashboard

## Modules

- `backend/` — Spring Boot REST API
- `frontend/` — React web application

## Initial Goals

- Expose VisionLab benchmark and experiment results through a REST API
- Browse experiment runs
- Inspect individual run details
- Compare image-processing algorithms
- Compare software architectures
- Visualize benchmark and experiment results
